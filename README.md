# Breakout Ball Game

## Overview
The **Breakout Ball Game** is a classic arcade game where a player controls a paddle to bounce a ball and break bricks. The objective is to destroy all the bricks without letting the ball fall off the screen.

## Features
- Player-controlled paddle
- Ball movement with collision physics
- Breakable bricks with different properties
- Score tracking
- Multiple levels with increasing difficulty
- Sound effects and animations

## Technologies Used
- **Programming Language**: Python / JavaScript
- **Framework**: Pygame (Python) / HTML, CSS, JavaScript (Web version)
- **Physics Engine**: Basic 2D collision detection
- **Graphics**: Simple shapes and sprite-based animations

## How to Play
1. Run the game script (`breakout.py` for Python or `index.html` for web version).
2. Use the **left** and **right arrow keys** (or mouse) to move the paddle.
3. Bounce the ball off the paddle to break the bricks.
4. Clear all the bricks to proceed to the next level.
5. Lose a life if the ball falls below the paddle.
6. The game ends when all lives are lost or all levels are cleared.

## Installation
### Python Version
1. Install Python (if not installed).
2. Install Pygame:  
   ```sh
   pip install pygame
   ```
3. Run the game:  
   ```sh
   python breakout.py
   ```

### Web Version
1. Open `index.html` in a browser.
